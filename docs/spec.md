# Техническое задание

## Роли

| Роль | Кто | Что делает |
|---|---|---|
| Родитель | владелец системы | настраивает игры, детей, лимиты; смотрит статистику в Android-приложении |
| Ребёнок | 2 и более детей | запускает игры на ПК, входит в свой профиль по PIN |
| ПК | Windows 10/11 | отслеживает игры, считает время, блокирует |

## Учётные записи Windows

- Дети работают в **одной обычной учётной записи Windows без прав администратора**. Это обязательно:
  с правами администратора ребёнок может остановить службу.
- У родителя отдельная учётная запись администратора. Установка программы — только из неё.

## Основные сценарии

### С1. Включение ПК
ПК включается, служба стартует автоматически. Активного ребёнка нет. Обычные программы
(браузер, учебные приложения) работают без ограничений.

### С2. Запуск игры без активного ребёнка
1. Ребёнок запускает игру из списка контролируемых.
2. Служба сразу приостанавливает процесс игры.
3. Агент показывает окно «Кто играет?» со списком детей и полем PIN.
4. PIN верный и время осталось → игра продолжается, начинается сессия ребёнка.
5. PIN неверный → повтор. После 5 ошибок подряд профиль блокируется на 5 минут.
6. Время закончилось или сейчас запрещённые часы → сообщение, игра закрывается.
7. Окно закрыли, не выбрав ребёнка → игра закрывается.

### С3. Игра в активной сессии
Запуск других игр не требует повторного входа. Время идёт, пока запущена **хотя бы одна**
контролируемая игра: две игры одновременно не списывают время дважды.

### С4. Окончание времени
1. Предупреждения за 10, 5 и 1 минуту (уведомление и значок в трее).
2. В 0 минут игры получают команду закрыться (`WM_CLOSE`), через 30 секунд закрываются принудительно.
3. Повторный запуск в этот день блокируется до изменения лимита родителем.

### С5. Завершение сессии
Сессия ребёнка завершается:
- по кнопке «Выйти» в агенте;
- при блокировке экрана, выходе из Windows, сне;
- если контролируемые игры не запущены 10 минут (настраивается).

После этого следующий запуск игры снова спрашивает, кто играет.

### С6. Без интернета
ПК работает полностью автономно: лимиты и хэши PIN хранятся локально, статистика копится
и отправляется при появлении связи.

### С7. Родитель в приложении на телефоне (этап 2)
- статистика за день, неделю, по каждому ребёнку и игре;
- дневной лимит на ребёнка: отдельно для будней и выходных;
- разрешённые часы (например, 15:00–20:00);
- добавить или удалить ребёнка, переименовать, сменить PIN;
- список контролируемых игр: добавить по пути к exe, выбрать из запущенных на ПК процессов;
- добавить время «сегодня» (+15, +30 минут);
- уведомления: время закончилось, ПК работал без связи со службой.

### С8. Запрос дополнительного времени (этап 3)
Ребёнок в агенте нажимает «Попросить ещё». Родитель получает push-уведомление и одобряет или отклоняет.

## Требования

### Надёжность учёта
- Время считается по монотонным часам (`GetTickCount64`), а не по системному времени.
- Сон и гибернация не учитываются.
- Каждую минуту использование сохраняется на диск, чтобы при сбое питания терялось не больше минуты.

### Распознавание игр
Правило игры может включать:
- полный путь к exe (без учёта регистра);
- имя exe;
- подстроку командной строки (например, для Minecraft: `javaw.exe` + `minecraft`);
- SHA-256 exe (защита от переименования, этап 3).

Браузерные игры на этапе 1 не поддерживаются.

### Безопасность
- PIN хранится только в виде хэша PBKDF2-HMAC-SHA256 с солью.
- Файлы конфигурации лежат в `%ProgramData%\KidsTimeControl`, запись разрешена только SYSTEM и администраторам.
- Служба настроена на автоматический перезапуск при сбое.
- ПК регулярно отправляет в облако сигнал «жив», пропуски видны родителю (этап 2).
- Цель — сделать обход сложным и заметным. Защиты от безопасного режима, переустановки Windows
  или загрузки с флешки нет и не будет.

### Приватность
Собирается только то, что нужно для контроля: какие контролируемые игры, кем и сколько запускались.
Снимки экрана, клавиатура, история браузера и прочие программы не отслеживаются.

## Вне рамок первой версии
- macOS и Linux;
- контроль браузерных сайтов;
- несколько семей на одном ПК.
