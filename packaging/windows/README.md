# Установка службы на ПК

Архив `kids-time-control-windows.zip` собирается в CI (артефакт в GitHub Actions) и содержит:

| Файл | Что это |
|---|---|
| `ktc.exe` | программа (служба + утилита командной строки) |
| `KidsTimeControl.exe` | [WinSW](https://github.com/winsw/winsw) v2: регистрирует `ktc.exe service` как службу Windows |
| `KidsTimeControl.xml` | настройки службы: автозапуск, LocalSystem, перезапуск при сбое, журналы |
| `agent\` | агент в трее (`ktc_agent.exe`, Flutter): окно «Кто играет?», уведомления, «Выйти» |
| `install.ps1`, `uninstall.ps1` | установка и удаление |

## Сначала: учётная запись для детей

Дети должны входить в Windows под **обычной** учётной записью, не администратором: администратор
может остановить службу. Создайте её в «Параметры → Учётные записи → Другие пользователи»
(тип «Стандартный пользователь»), а пароль администратора оставьте себе. Одной такой записи
достаточно на всех детей: кто играет, различается по PIN.

`install.ps1` покажет, какие учётные записи — администраторы, и предупредит, если обычных нет.
Если ребёнок всё же окажется за ПК под администратором, приложение родителя покажет
предупреждение на вкладке «Компьютеры».

## Установка

В **PowerShell от имени администратора** в папке с распакованным архивом:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт:
1. копирует файлы в `C:\Program Files\KidsTimeControl`;
2. создаёт `C:\ProgramData\KidsTimeControl` и оставляет доступ к ней только SYSTEM и администраторам —
   ребёнок с обычной учётной записью не прочитает хэши PIN и не исправит статистику;
3. регистрирует и запускает службу **Kids Time Control** (автозапуск, перезапуск при сбое);
4. ставит агент в трее в автозапуск для всех пользователей Windows и запускает его сейчас.

Затем привяжите ПК к семье (в том же окне администратора):

```powershell
& "$env:ProgramFiles\KidsTimeControl\ktc.exe" pair --api-key <Web API Key> --project-id <ID проекта> --name "Домашний ПК"
```

Служба сама синхронизируется раз в минуту. Журналы — `C:\ProgramData\KidsTimeControl\logs`.

## Как это выглядит для ребёнка

1. Ребёнок запускает игру — она сразу встаёт на паузу, появляется окно «Кто играет в …?».
2. Он выбирает своё имя и вводит PIN — игра продолжается. «Отмена» или неверный PIN три раза
   подряд — игра закрывается. После 5 неверных PIN вход блокируется на 5 минут.
3. За 10, 5 и 1 минуту до конца — уведомление; когда время вышло — 30 секунд, чтобы сохраниться,
   потом игры закрываются, и за ПК может сесть брат или сестра.
4. Значок-часы в трее показывает, кто играет и сколько осталось; «Выйти (сменить игрока)» —
   следующая игра снова спросит, кто играет. Блокировка экрана (Win+L) тоже завершает сессию.

Служба сама не может показывать окна (она работает в отдельной сессии Windows), поэтому без
агента спросить «кто играет» некому и **игры закрываются**. Закрыть агент, чтобы обойти контроль,
не получится.

Проверить вход без агента можно в консоли администратора:

```powershell
& "$env:ProgramFiles\KidsTimeControl\ktc.exe" service --console
```

(перед этим остановите службу: `Stop-Service KidsTimeControl`).

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1              # данные сохраняются
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1 -RemoveData  # вместе с данными
```
