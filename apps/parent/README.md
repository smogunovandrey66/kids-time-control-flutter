# Родительское приложение

Этап 2. Flutter для Android (при желании и iOS), Firebase Auth, Firestore и Cloud Messaging.
Использует `ktc_core` для хэширования PIN и описания правил игр. За основу архитектуры берётся
[flutter-showcase](https://github.com/smogunovandrey66/flutter-showcase): Riverpod, go_router, freezed.
